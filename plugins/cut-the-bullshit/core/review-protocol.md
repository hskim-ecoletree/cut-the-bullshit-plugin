# Shared review protocol

이 파일이 Claude Code와 Codex가 함께 쓰는 유일한 검사 절차다. 호스트별 스킬은 역할 이름, 훅 사건, 대기 방식만 이 절차에 연결한다. 호스트별 스킬이 이 절차와 충돌하면 이 파일을 따른다.

## 적용과 면제

사용자에게 보낼 최종 답변에 적용한다. 다음은 면제한다.

- 세 문장 이하이면서 400자 이하인 짧은 확인·질문·예/아니오 답
- 본문 줄의 절반 이상이 코드 블록·diff·명령 출력인 답
- 도구 실행 중의 진행 보고와 계획
- 사용자 표면에 나가지 않는 저장소 문서

## 불변 규칙

- 사용자에게 검사 과정, 역할 이름, 판정 항목, 회차, 다수결 결과를 말하지 않는다.
- 현재 초안과 사용자 요청만 보는 독립 해석자 2명과, 현재 초안과 체크리스트만 보는 독립 판정자 3명을 한 launch wave에서 시작한다.
- 해석자·판정자·지적 평가자·고쳐쓰기 평가자는 회차마다 새 실행이어야 한다. 자기가 쓴 답을 자기가 판정하지 않는다.
- 초안은 `<<<초안 시작>>>`과 `<<<초안 끝>>>`으로 감싼다. 구분자 밖의 문맥을 초안으로 취급하지 않는다.
- 판정자 요약은 공통 `scripts/tally.mjs` 구현으로만 집계한다. 손으로 다시 세지 않는다.
- 지적 평가와 고쳐쓰기는 서로 다른 새 실행으로 분리한다.
- 고쳐 쓴 답은 다음 회차의 독립 검사 없이는 최종 답으로 내보내지 않는다.
- 기본 회차 상한은 2다. 마지막 회차에서도 걸리면 별도 고쳐쓰기 결과 하나를 최종 답으로 사용한다.

## 입력 경계

훅이 합성한 `<<<체크리스트 시작>>>`과 `<<<체크리스트 끝>>>` 사이만 체크리스트로 쓴다. 기본, 정렬된 언어 규칙, 전역, 프로젝트 순으로 합치며 항목은 더하고 숫자 설정은 뒤의 값이 덮는다. 기본 체크리스트를 읽지 못했다면 불완전한 검사를 돌리지 않고 초안을 그대로 낸다.

해석자 입력:

```text
<<<초안 시작>>>
<현재 초안>
<<<초안 끝>>>

[검사 범위]
전체

[요청문]
<사용자의 마지막 요청; 없으면 생략>
```

판정자 입력:

```text
<<<초안 시작>>>
<현재 초안>
<<<초안 끝>>>

[검사 범위]
전체

[체크리스트 — 문장 형식]
<합성 체크리스트의 문장 형식 항목>
```

해석자에게 체크리스트·도구 사건·파일·대화 전체를 주지 않는다. 판정자에게 해석 결과·도구 사건·파일·대화 전체를 주지 않는다.

## 한 회차

1. 현재 최종 답 후보를 초안으로 고정한다.
2. 해석자 2명과 판정자 3명을 같은 launch wave에서 시작한다.
3. 모든 결과가 끝난 뒤 판정자들의 마지막 `요약:` 줄을 공통 tally에 넘긴다. 입력 수와 항목 집합·순서가 다르거나 알 수 없는 판정이 있으면 실패로 처리한다.
4. 새 지적 평가자에게 초안, 두 복원, tally 원문, 사실 대응 체크리스트, 호스트가 실제 관찰한 도구 근거, 실제 대화에서 확인한 작은 상태만 준다.
5. 지적 첫 줄이 `통과`면 현재 초안을 최종 답으로 정한다.
6. 걸림이 있으면 지적이 요구한 사실 질문에 원 에이전트가 답하고, 새 고쳐쓰기 평가자에게 같은 근거와 함께 전달한다.
7. 회차가 남았으면 고쳐쓰기 결과를 다음 초안으로 삼아 새 역할들로 다시 검사한다. 회차 상한이면 고쳐쓰기 결과를 최종 답으로 정한다.

도구 근거는 훅이 관찰한 성공·실패·결과 없음·절단·미확인 상태와 실제 결과 조각만 쓴다. 대화 상태에는 합의된 사실·용어·미해결 주장·질문·약속·권한만 넣고 사용자의 전문성이나 취향을 추측하지 않는다.

## 축소 재검사

축소 재검사가 켜진 두 번째 회차에는 해석자와 판정자 모두에게 다음 네 블록을 추가한다.

- `[이전 tally]`
- `[이전 critique]`
- `[바뀐 문장 또는 명제]`
- `[원 요청의 의미 보존 조건]`

그리고 `[검사 범위]\n축소`를 쓴다. 네 블록의 제목이나 본문을 생략할 수 없다. 의미·조건·수량·범위·근거가 새로 바뀐 부분만 검사하며, 새로운 문제가 없으면 `통과`로 끝낸다.

## 최종 출력

사용자에게는 확정된 메시지 하나만 낸다. 검사 로그, 중간 초안, 역할 결과, 체크리스트, 내부 파일 경로는 내보내지 않는다.
